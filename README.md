# マグロ部位パズル

マグロを 3D で分解・組み立てしながら、部位の名前をおぼえる知育パズルです。
魚の部位の名前をおぼえるために、個人で作ったものです。実在の商品・企業とは関係ありません。

## 遊び方

- **分解** … 手前の皮からタップしてパーツを外していきます（全27パーツ）
- **組み立て** … 下のパーツ置き場からドラッグしてはめ込みます。上にかぶさるパーツがあると、はまりません
- ドラッグで回転、ホイール／2本指で拡大

部位の名前（せかみ・せなか・せしも・あかみ・はらかみ・はらなか・はらしも・カマ・中落ちなど）は、
魚市場で使われている一般的な呼び方です。

## 公開

`docs/` を GitHub Pages で公開しています。スマホでは「ホーム画面に追加」すると、
アプリのように全画面で開き、オフラインでも遊べます（PWA）。

検索エンジンの結果には出さない設定にしています（`noindex` メタタグ）。
robots.txt ではクロールを **許可** しています。ここで拒否すると noindex を読んでもらえず、
URL だけが検索結果に載ってしまうためです。

なお、noindex はあくまで「検索に出さない」だけで、URL を知っている人は誰でも開けます。

## 構成

```
src3/shell3.html   画面まわり（HTML/CSS）
src3/geom3.js      マグロの立体パーツの形（部位マスタ）
src3/app3.js       3D表示・操作・進行
src3/sw.js         Service Worker のもと
build3.py          ビルド（→ index.html と docs/ を書き出す）
docs/              GitHub Pages で公開する中身
```

更新するときは `src3/app3.js` の `APP_VERSION` を上げてから `python3 build3.py` を実行します。
Service Worker の版数も自動で合わせます。

3D描画に [three.js](https://threejs.org/)（r128, MIT License）を同梱しています。
